# 📄 Documentação — Portfólio Pessoal (Dev / Estudante de ADS)

Este repositório de documentação reúne todo o processo de engenharia de requisitos e planejamento do projeto **Portfólio Web Pessoal**, desenvolvido por um estudante de Análise e Desenvolvimento de Sistemas com o objetivo de conseguir estágio ou primeira oportunidade como desenvolvedor.

A documentação foi estruturada seguindo boas práticas de Engenharia de Software (elicitação de requisitos, escopo, requisitos funcionais/não funcionais, personas e arquitetura), servindo tanto como guia de desenvolvimento quanto como **peça do próprio portfólio** — evidenciando domínio de processo, não apenas de código.

## 🎯 Resumo rápido do projeto

- **Objetivo principal:** Conseguir estágio ou primeiro emprego como desenvolvedor
- **Público-alvo:** Recrutadores técnicos e gestores de RH/Tech
- **Estilo visual:** Minimalista/clean, foco em conteúdo
- **Stack:** React (framework JS)
- **Hospedagem:** Vercel ou Netlify
- **Diferenciais exigidos:** Responsivo, modo claro/escuro, acessível, otimizado para SEO
- **Metodologia de desenvolvimento:** Uso de agentes de IA como par de desenvolvimento, sem prazo fixo

## 🧭 Como usar esta documentação

1. Comece pelo **escopo** para entender os limites do projeto.
2. Leia a **elicitação de requisitos** para entender o "porquê" de cada decisão.
3. Use os **requisitos funcionais/não funcionais** como checklist de desenvolvimento.
4. Consulte **arquitetura e stack** antes de iniciar a codificação.
5. Acompanhe o progresso pelo **cronograma**, adaptando as fases livremente.
