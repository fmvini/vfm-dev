# Portfólio de Vinícius Fatichi Marrocos

Página única em React e Vite, criada a partir dos requisitos em `docs/` e dos dados de `docs/Curriculo.md`.

## Rodar localmente

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
npm run preview
```

## Conteúdo

Os dados de contato, habilidades e certificações ficam em `src/data/profile.js`. Os textos das seções e do projeto estão em `src/App.jsx`.

O formulário prepara uma mensagem no aplicativo de e-mail do visitante. Para envio direto pelo site, será necessário configurar um serviço de formulário e testar a entrega. O currículo em PDF, a foto e os links específicos para repositório e demo do VFitness ainda dependem de arquivos ou URLs fornecidos pelo proprietário.
